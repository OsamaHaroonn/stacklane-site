    Images

    Image resizer

    Set the width or height you need, keep the aspect ratio locked, and download the resized image. The file is handled entirely inside your browser.

    Runs locally in your browser

    How it works

    Your browser decodes the file into pixels, then draws those pixels onto a canvas of the size you asked for. When shrinking, the tool samples the image down; when growing, it simply makes each pixel bigger, which softens detail — no tool can invent detail that was never in the file. The result is encoded as JPEG, PNG or WebP, matching the input unless you choose otherwise.

    Worked example

    A 4032 × 3024 phone photo resized to 1200 px wide comes out at 1200 × 900 with the ratio preserved, and is usually a few hundred kilobytes instead of several megabytes. Resizing that same photo up to 4000 px would produce a large file with no extra detail.

    Questions and answers

    Is my photo uploaded?

    No. Decoding, resizing and download happen on your device only. Nothing is sent to a server.

    Does upscaling ruin quality?

    It does not add detail. Small increases are usually fine; enlarging far beyond the original makes the image soft and blocky, because the software is guessing the in-between pixels.

    Why does the height change when I type a width?

    The aspect ratio lock keeps the picture undistorted. Unlock it only if you deliberately want to stretch or squash the image.

    Which format should I download?

    JPEG for photographs, PNG for screenshots and transparency, WebP for the smallest files where it is supported. The tool keeps your original format unless you change it.

    What if the result is bigger than the original?

    Enlarging adds pixels, and sometimes a re-encoded file grows slightly. The tool shows the real size after resizing so you can decide before downloading.
