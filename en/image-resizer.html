Image resizer

Set the width or height you need, keep the aspect ratio locked, and download the resized image. The file is handled entirely inside your browser.

Runs locally in your browser

How it works

Your browser decodes the file into pixels, then draws those pixels onto a canvas of the size you asked for. When shrinking, the tool samples the image down; when growing, it simply makes each pixel bigger, which softens detail — no tool can invent detail that was never in the file. The result is encoded as JPEG, PNG or WebP, matching the input unless you choose otherwise.

Worked example

A 4032 × 3024 phone photo resized to 1200 px wide comes out at 1200 × 900 with the ratio preserved, and is usually a few hundred kilobytes instead of several megabytes. Resizing that same photo up to 4000 px would produce a large file with no extra detail.
