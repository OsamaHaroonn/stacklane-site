    Coin flipper

    Flip a coin as many times as you like and watch the heads and tails counts build up, with the share of each side shown as it goes.

    Runs locally in your browser

    How it works

    Each flip asks the browser for one 32-bit random number and takes it modulo 2: an even number is heads, an odd number is tails. A 32-bit number has 2^32 possible values, and 2^32 is even, so the two outcomes split the range exactly in half, with 2^31 values each. Nothing is discarded and neither side is favoured. The helper this page uses also contains a guard that would redraw values for a range that does not divide 2^32 evenly, but with two outcomes that guard can never fire. Every flip is independent of the ones before it. The counters live in this page only: they start at zero and go back to zero when you press reset or reload. Each percentage is that count divided by the total flips so far.

    Worked example

    If the first four flips came out heads, tails, heads, heads, the counter would read heads 3, which is 3 ÷ 4 × 100 = 75.0%, tails 1, which is 25.0%, and a total of 4. Each flip is independent, so that 75% is just what happened in those four flips, not a prediction for the next one.

    Questions and answers

    Is it really 50/50?

    Yes, exactly. Each flip takes one 32-bit random number modulo 2. Because 2^32 divides evenly by 2, heads and tails each come from exactly 2^31 of the possible values, so nothing is rounded away and no value is discarded. The flips are independent, so earlier results do not change the next one.

    Does it remember my previous flips?

    Only for this visit, in the page's memory. Reloading or pressing reset clears the counts, and nothing is written to storage or sent anywhere.

    Are the flips independent?

    Yes. No flip looks at the ones before it, so a run of heads does not change the chance of the next result.

    Is this a physics simulation?

    No. It does not model a real coin's spin or weighting; it draws a random outcome with equal probability, which is the property you want from a coin toss.

    What does reset do?

    Sets both counters back to zero and clears the last result, so the next flip starts a fresh run.
