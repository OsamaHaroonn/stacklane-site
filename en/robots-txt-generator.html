    Robots.txt generator

    Choose what crawlers may fetch, list any paths of your own, and copy a finished robots.txt with each directive explained.

    Runs locally in your browser

    How it works

    The file is built from directives, one per line. User-agent names the crawler the following rules apply to, and an asterisk means all of them. Disallow lists paths that must not be fetched, and an empty Disallow means nothing is blocked, which is how a file allows everything. A line starting with a bang in the paths box becomes an Allow line instead, so you can block a folder and reopen one file inside it. Blank lines separate groups and are ignored. The optional Sitemap line takes a full URL and points crawlers at the sitemap; it is not part of any group. Paths must start with a slash. The output is plain text you can copy or download as robots.txt.

    Worked example

    With "allow everything" selected and the sitemap https://YOURDOMAIN.com/sitemap.xml, the tool writes three lines: User-agent: * then Disallow: with nothing after it, then a blank line and Sitemap: https://YOURDOMAIN.com/sitemap.xml. The empty Disallow is deliberate: it means no path is blocked, which is the usual way to say everything is allowed.

    Questions and answers

    Does robots.txt remove a page from search results?

    Not reliably. It asks crawlers not to fetch a URL, but a blocked page can still appear in results if other sites link to it. To keep a page out of results, let it be crawled and send a noindex robots meta tag instead.

    Where does robots.txt have to live?

    At the root of the domain, so the address is https://YOURDOMAIN.com/robots.txt. A copy in a subfolder is not read for that domain.

    What does an empty Disallow line mean?

    Nothing is disallowed, so every path may be fetched. That is the standard way to allow a whole site while still naming the user agent.

    Can I block a folder but allow one file inside it?

    Yes, in custom mode. Add a line for the folder and prefix the file's line with an exclamation mark to make it an Allow rule; most crawlers then use the longest matching rule.

    Do all crawlers follow these rules?

    Most well-known search crawlers do. Any crawler is free to ignore the file, so it is a request rather than a lock.
