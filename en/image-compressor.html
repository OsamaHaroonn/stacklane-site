Image compressor

Choose an image, set the quality, and see exactly how much smaller the result is. The picture is processed inside your browser and never uploaded.

Runs locally in your browser

How it works

The file is decoded into pixels by your browser, then re-encoded at the quality you choose. JPEG and WebP are lossy formats, so lower quality means fewer bits and a smaller file, with visible detail loss below a certain point. PNG is lossless, so re-encoding it can only shrink the file if the image has fewer colours than before — otherwise the result can be larger, and the tool says so.

Worked example

A 3.2 MB photo set to 75% JPEG quality may come back near 400 KB — about an eighth of the size, with the difference mostly invisible at normal screen size. The same file saved as lossless PNG would be far larger, not smaller, which is why the tool reports the real numbers rather than promising a percentage.
