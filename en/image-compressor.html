    Images

    Image compressor

    Choose an image, set the quality, and see exactly how much smaller the result is. The picture is processed inside your browser and never uploaded.

    Runs locally in your browser

    How it works

    The file is decoded into pixels by your browser, then re-encoded at the quality you choose. JPEG and WebP are lossy formats, so lower quality means fewer bits and a smaller file, with visible detail loss below a certain point. PNG is lossless, so re-encoding it can only shrink the file if the image has fewer colours than before — otherwise the result can be larger, and the tool says so.

    Worked example

    A 3.2 MB photo set to 75% JPEG quality may come back near 400 KB — about an eighth of the size, with the difference mostly invisible at normal screen size. The same file saved as lossless PNG would be far larger, not smaller, which is why the tool reports the real numbers rather than promising a percentage.

    Questions and answers

    Is my picture uploaded?

    No. Decoding, re-encoding and download all happen in your browser. The file never leaves your device.

    Which quality should I pick?

    Around 80% is a good default for photos. Use 60–70% when file size matters more than fine detail, and 90%+ when the image will be printed or cropped.

    Why did my PNG get bigger?

    PNG is lossless: the re-encoder keeps every bit of detail, and if your browser's encoder is less efficient than the original, the file grows. The tool reports the real size, and you can choose JPEG instead.

    Which format should I use?

    JPEG or WebP for photographs and anything with gradients. PNG for screenshots, logos and transparency. WebP is usually smallest but is not accepted everywhere.

    Why does it struggle with very large files?

    The image has to be held as raw pixels in memory, so a very large photo can take a while or fail on a phone. The tool shows progress and reports a clear error instead of freezing the tab.
