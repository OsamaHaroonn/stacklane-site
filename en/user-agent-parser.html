User agent parser

Paste a user agent string, or read the one your browser sends, to see the browser, version, rendering engine, operating system and device type.

Runs locally in your browser

How it works

The string is matched against a fixed set of patterns in order, because browsers copy each other's tokens: Edge keeps Chrome and Safari tokens, and Chrome keeps Safari's. The order is Edge first, then Opera, Firefox, Chrome and Safari, so the most specific marker wins. The engine follows from the browser family, with Firefox using Gecko, the Chromium family using Blink and Safari using WebKit. The operating system comes from Windows NT version numbers, Android and iOS markers, or macOS and Linux tokens. The device is a tablet when an iPad or tablet marker is present, a mobile when a mobile or Android marker is, and a desktop otherwise. A string containing a bot, crawler, spider or headless marker is flagged.

Worked example

For Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36 the tool reports Chrome, version 120.0, engine Blink, operating system Windows 10 or 11, device desktop, and automated no. The Safari token in the same string is ignored because the Chrome marker is checked first.
