    JSON formatter

    Paste JSON to format it with indentation, minify it to save space, or check that it is valid. The data is processed in your browser and never sent anywhere.

    Runs locally in your browser

    How it works

    The input is parsed with the browser's own JSON parser, which is the same standard every language implements. Formatting re-serialises the parsed value with a chosen indentation; minifying does the same with no whitespace. Because parsing happens first, a syntax error is reported before anything is printed — with the position in the text where the parser stopped.

    Worked example

    The compact string {"a":1,"b":[true,null,"x"]} formats across four lines with two-space indentation, showing that b is an array of three items. Minifying it again returns byte-for-byte the same compact text, since whitespace outside strings carries no meaning.

    Questions and answers

    Is my JSON sent anywhere?

    No. Parsing, formatting and validation all happen in your browser tab. Nothing is transmitted or stored.

    What is the difference between format and minify?

    Formatting adds indentation and line breaks so the structure is readable. Minifying removes every optional whitespace to make the smallest possible version. Neither changes the data.

    Why does my JSON fail to parse?

    The usual causes are a trailing comma after the last item, single quotes instead of double quotes, or an unquoted key. The message tells you where the parser stopped so you can jump straight to it.

    Does it check my data against a schema?

    No. It checks syntax only — that the text is valid JSON. Whether the structure matches what your program expects is a separate check.

    Is there a size limit?

    There is no fixed limit, but very large documents take time and memory to parse. If nothing appears after a moment, the document is probably too big for this page — split it up.
