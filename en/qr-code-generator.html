QR code generator

Type a link or any short text and get a QR code you can download as a PNG. The code is drawn by your browser — the content is never sent anywhere.

Runs locally in your browser

How it works

Your text is encoded into a QR symbol: the characters become a numeric value, which is laid out on a square grid with error-correction data added so the code still scans if part of it is damaged or dirty. Larger inputs need more grid cells, so the code gets denser. The image is drawn on a canvas in your browser and exported as a PNG.

Worked example

A link such as “https://example.com/menu” produces a compact code that scans from a few centimetres away. A 400-character Wi-Fi configuration produces a denser grid that needs to be printed larger to scan reliably.
