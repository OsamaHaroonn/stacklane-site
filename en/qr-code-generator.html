    QR code generator

    Type a link or any short text and get a QR code you can download as a PNG. The code is drawn by your browser — the content is never sent anywhere.

    Runs locally in your browser

    How it works

    Your text is encoded into a QR symbol: the characters become a numeric value, which is laid out on a square grid with error-correction data added so the code still scans if part of it is damaged or dirty. Larger inputs need more grid cells, so the code gets denser. The image is drawn on a canvas in your browser and exported as a PNG.

    Worked example

    A link such as “https://example.com/menu” produces a compact code that scans from a few centimetres away. A 400-character Wi-Fi configuration produces a denser grid that needs to be printed larger to scan reliably.

    Questions and answers

    Is the content sent anywhere?

    No. Encoding and drawing both happen in your browser. Nothing you type is transmitted or stored.

    What can I put in a QR code?

    A website link, plain text, an email address, a phone number, or connection details for a Wi-Fi network. Links are the most reliable because phones open them directly.

    Why is my code hard to scan?

    Usually it is too small for the amount of data, or it lacks quiet space around it. Print it larger, keep a clear margin on all four sides, and make sure it is printed in high contrast on a plain background.

    Is there a length limit?

    Yes. The largest QR version holds about 2,900 bytes of ordinary text. Past that the tool reports an error instead of drawing a code that would not scan.

    Does the colour or shape matter?

    This tool draws the standard black-on-white code, which every reader supports. Extreme colours or rounded modules may look better but reduce how reliably phones scan them.
