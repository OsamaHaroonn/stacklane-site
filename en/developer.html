    Developer

    Format, validate and encode data you are working with.

    What these tools do

    Format and validate JSON, encode Base64 and URLs, decode JWTs, compare colours, test regular expressions, hash text, format SQL, and generate meta tags and sitemaps. Output is produced locally.

    22 tools in this category. Everything runs in your browser: nothing you type or open is uploaded.

    JSON formatter

    Format, minify and validate JSON in your browser, with a clear error message when the syntax is wrong.

    →

    Base64 encoder

    Encode text to Base64 and decode it back, with UTF-8 handled correctly in both directions.

    →

    URL encoder

    Percent-encode text for a URL or query string, and decode it back again.

    →

    Timestamp converter

    Turn a Unix timestamp into a readable date and time, and a date and time back into a timestamp.

    →

    Color converter

    Convert a hex colour code to RGB and HSL, with the working shown and a swatch to check it.

    →

    Regex tester

    Test a JavaScript regular expression against your own text and see every match, capture group and position, with flags and clear errors for invalid patterns.

    →

    Hash generator

    Create a SHA-1, SHA-256, SHA-384 or SHA-512 hash of any text using your browser's Web Crypto API. The text never leaves the page.

    →

    Colour contrast checker

    Check the WCAG 2 contrast ratio between two colours and see the AA and AAA results for normal and large text. Free, instant and private.

    →

    HTML entity encoder

    Encode text into HTML entities or decode entities back to plain text. The output stays text, never markup, and everything runs in your browser.

    →

    JWT decoder

    Decode a JWT header and payload in your browser. The token is never sent, never verified, and a decoded token proves nothing about its validity.

    →

    CSV to JSON converter

    Convert CSV to JSON or JSON to CSV in your browser, with quoted fields, embedded commas and line breaks inside quotes handled correctly. Nothing is uploaded.

    →

    Image to Base64 encoder

    Turn an image into a Base64 data URI in your browser. The file is never uploaded, the size limit is stated, and the result comes with a copy button.

    →

    Meta tag generator

    Build a title, description, canonical, Open Graph and Twitter card block as plain text, with length counters as you type. Nothing is uploaded.

    →

    Robots.txt generator

    Write a robots.txt in plain text: allow everything, block everything or list your own paths, then add a sitemap line. Free, in your browser.

    →

    XML sitemap generator

    Paste page URLs to get a valid sitemap.xml: escaped characters, duplicates removed, and your chosen change frequency and priority.

    →

    CSS box shadow generator

    Set offset, blur, spread, colour and opacity to build a box-shadow rule, copy the CSS and see it on a sample card. Inset is supported.

    →

    Color palette generator

    Enter a hex colour to get five swatches: two tints mixed with white, the base, and two shades mixed with black, with hex and rgb values.

    →

    CSS gradient generator

    Add colour stops, pick an angle and copy the exact CSS linear-gradient rule, with a live preview on the page.

    →

    Password strength checker

    Estimate a password's entropy from its length and the character classes it uses. Runs in the page and is never stored, sent or logged.

    →

    HTML to Markdown converter

    Paste HTML to get Markdown: headings, bold, italics, links, lists, quotes, code and tables, written as text only. Nothing is executed.

    →

    User agent parser

    Paste a user agent string or read your own to see the browser, version, engine, operating system and device type. Results are approximate.

    →

    SQL formatter

    Paste a SQL statement to get it formatted: keywords uppercased, clauses on their own lines, quoted strings untouched. Formatting only.
