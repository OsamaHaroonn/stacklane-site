    PDF page counter

    Choose a PDF and read its page count, byte size, title and producer. The document never leaves your browser.

    Runs locally in your browser

    How it works

    The file is read into memory and parsed with pdf-lib, which is loaded only when you pick a file. The page count comes from the PDF's own page tree, so it matches what a PDF reader shows. Size is the raw byte length of the file. Title and producer are the optional metadata fields the creating application wrote; many PDFs leave them empty, in which case the report says so. Encrypted PDFs are opened with decryption ignored, so page counts still work but their content cannot be altered.

    Worked example

    A 24-page catalogue exported from a design tool reports 24 pages, 1.8 MB, the title set by the exporter and the producing application. A scan with no metadata reports the page count and size with title and producer marked unknown.

    Questions and answers

    Is my PDF uploaded to a server?

    No. The file is read by JavaScript in this tab and discarded when you close the page or choose another file. Nothing is transmitted and nothing is stored.

    Which PDFs can it read?

    Any well-formed PDF, including ones made by common office and design tools. Password-protected files are opened with decryption ignored, so the page count is read but their contents stay encrypted. A damaged file that no reader can open will be reported as unreadable.

    Why is the page count different from what I expected?

    The count is the number of pages stored in the file. Blank pages, cover pages and pages hidden by an unusual viewer setting are all included, because they are all pages in the document.

    Can it count pages in several files at once?

    This tool reads one file at a time. Splitting a PDF into separate files is a separate tool on the site.
