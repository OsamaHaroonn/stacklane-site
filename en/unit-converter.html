How it works

Every conversion in a category is expressed against one base unit — metres for length, kilograms for mass — using exact, defined factors such as 1 inch = 25.4 mm. The value is converted to the base unit and then to the target unit, so any pair of units can be related through the same reference. Temperature is different: it uses formulas with an offset (°F = °C × 9/5 + 32) because the scales do not start at the same point, and Kelvin starts at absolute zero.

Worked example

10 kilometres is 10,000 metres, which is 6.2137 miles. Converting 25 °C uses the offset formula: 25 × 9/5 + 32 = 77 °F. Converting 0 °C gives 32 °F, not 0 — which is exactly why temperature cannot use a simple multiplier.
