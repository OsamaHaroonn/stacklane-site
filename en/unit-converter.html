    Unit converter

    Pick a category, choose the units, and type a value. The conversion runs in your browser and shows the exact factor it used.

    Runs locally in your browser

    How it works

    Every conversion in a category is expressed against one base unit — metres for length, kilograms for mass — using exact, defined factors such as 1 inch = 25.4 mm. The value is converted to the base unit and then to the target unit, so any pair of units can be related through the same reference. Temperature is different: it uses formulas with an offset (°F = °C × 9/5 + 32) because the scales do not start at the same point, and Kelvin starts at absolute zero.

    Worked example

    10 kilometres is 10,000 metres, which is 6.2137 miles. Converting 25 °C uses the offset formula: 25 × 9/5 + 32 = 77 °F. Converting 0 °C gives 32 °F, not 0 — which is exactly why temperature cannot use a simple multiplier.

    Questions and answers

    Are the conversion factors exact?

    Metric factors are exact by definition (1 inch is exactly 25.4 mm, 1 pound is exactly 0.45359237 kg). The displayed result is rounded, but the calculation uses the full value.

    Why is temperature handled differently?

    Temperature scales have different zero points, so converting needs an offset as well as a multiplier. The tool uses the standard formulas rather than a ratio.

    Which units are supported?

    Length, mass, volume, temperature and speed, covering the metric units and the common imperial and US units. More categories can be added later.

    Why does the result show so many decimals?

    It shows the exact converted value rounded to a sensible number of digits, with the full precision used in the calculation shown in the working line below.

    Does it work offline?

    Yes. Nothing needs the network: the factors are built into the page and the calculation happens in your browser.
