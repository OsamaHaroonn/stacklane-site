    Percentage change calculator

    Enter an original value and a new value to get the percentage change, the absolute difference and whether it went up or down.

    Runs locally in your browser

    How it works

    Percentage change is the difference divided by the size of the original value, times 100. Dividing by the size of the original means the sign always describes the movement: a change from −50 to −40 is an increase, not a decrease. A change from zero has no meaningful percentage, because every percentage of zero is zero, so it is reported as undefined with the absolute difference instead. The result is rounded to two decimals for display and the unrounded value is used in the summary.

    Worked example

    From 50 to 60 the change is +20%, the difference is +10 and the direction is an increase. From 80 to 60 the change is −25%, the difference is −20 and the direction is a decrease.

    Questions and answers

    What is the difference between percentage change and percentage points?

    Percentage change compares two values relative to the first. Percentage points describe the gap between two percentages: a rate moving from 5% to 7% rose by 2 percentage points, which is a 40% change. This tool reports the percentage change.

    Why is the change undefined when the original is zero?

    Percentage change is a ratio to the original value. With an original of zero there is no base to compare against, so any percentage would be misleading. The tool shows the absolute difference and says the percentage is undefined.

    Does it work with negative numbers?

    Yes. The calculation divides by the size of the original, so the direction is always reported correctly even when both values are below zero.

    Are the results rounded?

    Displayed percentages use two decimals. The summary sentence is built from the same rounded figure so the numbers on screen never disagree with each other.
