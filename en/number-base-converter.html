Number base converter

Enter a value in one base and read it in binary, octal, decimal, hexadecimal, base 36 and a custom base of your choice. Large values stay exact.

Runs locally in your browser

How it works

A base is the number of digits available. Decimal uses 0 to 9, binary uses 0 and 1, hexadecimal adds A to F, and a custom base up to 36 continues through Z. To read a value, the tool multiplies each digit's place from the right: the rightmost digit is worth base to the power 0, the next base to the power 1, and so on. To write it in another base it repeatedly divides and keeps the remainder, which becomes the next digit — 1000 divided by 2 is 500 remainder 0, and so on up to 1111101000. Every digit is parsed into a BigInt, so values far beyond the safe integer range convert without losing precision. Digits that do not belong to the chosen base are rejected with the offending character named.

Worked example

The value 1000 in decimal converts to 1111101000 in binary, 1750 in octal, 3E8 in hexadecimal and RS in base 36. Each of those reads back to exactly 1000, which is why the decimal row always repeats your input unchanged.
