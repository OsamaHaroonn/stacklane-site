    Case converter

    Paste your text, pick a case and read the result straight away. The conversion runs in this tab as you type, and you can copy the output in one click.

    Runs locally in your browser

    How it works

    The converter applies one string transform per case, in this tab, on every keystroke. Upper and lower case use the browser's own Unicode-aware mapping, so accented letters change with their plain counterparts. Title case capitalises the first letter of every run of letters and digits and lowercases the rest. Sentence case lowercases everything, then restores capitals after . ! ? and at the start of the text. The programming styles first split the text on anything that is not a letter or a digit: camelCase joins the parts with the first lower and later parts capitalised, snake_case and kebab-case join them in lower case with an underscore or a hyphen. Splitting on non-alphanumerics means punctuation and spaces are removed in those four modes — that is what makes an identifier, not a sentence.

    Worked example

    For stacklane tools 2024 the modes give: UPPER CASE → STACKLANE TOOLS 2024; title case → Stacklane Tools 2024; camelCase → stacklaneTools2024; snake_case → stacklane_tools_2024; kebab-case → stacklane-tools-2024. Notice the digits stay lowercase in camelCase because only the first letter of each part is capitalised, and a part that starts with digits gains no capital at all.

    Questions and answers

    Is my text uploaded anywhere?

    No. Every transform is a string operation inside your browser tab. Nothing is sent to a server and nothing is stored after you leave the page.

    Why does camelCase drop my spaces and commas?

    Because identifiers cannot contain them. The text is split on anything that is not a letter or a digit, and the parts are rejoined. If you need the punctuation kept, use upper, lower, title or sentence case.

    How does title case treat small words?

    It capitalises every word equally. Editorial title case would usually leave words like "and" lowercase in the middle of a title, which needs a word list and a language judgement this tool does not attempt.

    Does it handle accents and other scripts?

    Upper and lower case do, because they use the browser's own Unicode mapping. The word-splitting styles break on non-Latin scripts differently, since they treat a run of letters as one part — check the output before using it as an identifier.

    Is there a length limit?

    Yes, 500,000 characters. Transforms are re-run on every keystroke, so a longer paste would make typing lag; the tool refuses it with a message instead of freezing.
