Favicon generator

Choose an image and the tool draws it into six square PNG files, with a download button for each size and a progress bar as it works.

Runs locally in your browser

How it works

The image is decoded by the browser first, and an image that fails to decode is reported instead of producing blank files. Favicons must be square, so the largest centred square of your image is used and the rest is cropped away. That square is then drawn into a canvas at each size in the list, using the canvas smoothing settings, and each canvas is exported as a PNG blob. Every size gets its own download button, and the file size of each PNG is shown next to it. Uploads are capped at 5 MB and empty files are rejected, because an empty file cannot be decoded. The image never leaves the page: the canvas work happens in your browser.

Worked example

Upload a 1024 by 1024 PNG and the tool produces six files: 16, 32, 48, 180, 192 and 512 pixels square. Because the source is already square there is no crop, and the 512 file is exactly 512 by 512 pixels. A 1000 by 800 image would first be cropped to the centre 800 by 800 square, then scaled down to those same six sizes.
