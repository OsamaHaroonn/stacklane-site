Decision wheel

List the options you are choosing between, spin, and get one of them back as plain text with the chosen row marked in the list.

Runs locally in your browser

How it works

The text box is split on line breaks, each line is trimmed, and empty lines are dropped, so the options are exactly the lines you typed. A spin draws one random integer from zero up to the number of options minus one, using 32 random bits with rejection sampling so no option is favoured. Every option therefore has the same chance, one divided by the number of options. The chosen option is written into a live region as text and its row in the list is highlighted and marked as current, so a screen reader announces the result without a visual animation. Entries are capped at twenty options of sixty characters each, and the result is never treated as HTML.

Worked example

With the three options Walk, Bus and Train, each has a 1 ÷ 3 chance, which is 33.33%. One spin returns exactly one of the three, for example Bus, and that row is the only one marked as current; the next spin is a fresh draw and is not affected by the last result.
