    Barcode generator

    Encode text or numbers as a Code 128 barcode, preview it on the page, then download the SVG or copy the markup. Everything is computed locally.

    Runs locally in your browser

    How it works

    This is Code 128, code set B, which covers printable ASCII: letters, digits and common punctuation. The symbol is built as a start character, one value per character (the character code minus 32), a checksum, then the stop pattern. The checksum is the start value plus each data value multiplied by its position, all modulo 103, which is what a scanner uses to confirm it read the symbol correctly. Bars are drawn from the standard element-width table, each symbol eleven modules wide and the stop pattern thirteen, with a ten-module quiet zone either side. No network request is made and no library is loaded.

    Worked example

    The text “ABC” becomes start B, 33, 34, 35, then the checksum (104 + 33 + 68 + 105) mod 103 = 1, then stop — five symbols and 57 modules of ink, plus quiet zones.

    Questions and answers

    Will the barcode scan?

    The encoding follows the Code 128 specification: correct element widths, quiet zones and modulo-103 checksum, drawn as sharp SVG rectangles. Whether a particular scanner reads it depends on print size and contrast, so print at the module width you previewed rather than scaling the image down afterwards.

    Why are some characters rejected?

    Code set B only encodes printable ASCII (codes 32 to 126). Accented letters, emoji and other scripts need a different code set or a different symbology, so they are reported instead of being silently replaced.

    What are the numbers in the status line?

    The module count is the total width of the symbol in modules, including the quiet zones. The checksum is the value a scanner recomputes to verify the read.

    Can I use the SVG in a label or a document?

    Yes. SVG is vector, so it stays sharp at any size. Keep the aspect ratio, and avoid editing the shapes: changing bar widths by even one pixel can make the symbol unreadable.
