    CSS gradient generator

    Build a CSS linear-gradient from any number of colour stops, preview it on the page and copy the exact rule it produces.

    Runs locally in your browser

    How it works

    Colour stops are separated by commas or new lines and are normalised before use: three-digit hex is expanded to six, colour names are converted to hex, and rgb() or rgba() values are checked to be in range. The tool then writes linear-gradient(angle, stop, stop, …) and applies that same string to the preview, so the sample and the copied rule cannot drift apart. Angles are degrees, measured clockwise from the bottom of the element, which is how CSS defines them; “to right” and similar keywords are passed through unchanged.

    Worked example

    Stops #1d4ed8, #7c3aed and #f59e0b at 135 degrees produce background-image: linear-gradient(135deg, #1d4ed8, #7c3aed, #f59e0b); which runs from the top-left toward the bottom-right.

    Questions and answers

    Which colour formats are accepted?

    Six-digit and three-digit hex with or without the leading #, the common CSS colour names, and rgb() or rgba() with channels between 0 and 255. Anything else is rejected with a message naming the value that failed.

    Can I generate a radial gradient?

    Not with this tool. It writes linear gradients only, because the angle control and preview are specific to them.

    Is the copied CSS vendor-prefixed?

    No. linear-gradient has been supported unprefixed in every current browser for years, so the copyable rule is the standard property only.

    Where does the preview come from?

    The preview element has the generated rule applied directly, so what you see is the browser rendering the same CSS you copy.
