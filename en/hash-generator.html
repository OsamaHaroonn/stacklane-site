Hash generator

Paste text, choose an algorithm and get the hex digest. Hashing uses the browser's built-in Web Crypto implementation, so nothing is sent anywhere.

Runs locally in your browser

How it works

A hash function turns any input into a fixed-length fingerprint. This page calls crypto.subtle.digest over the UTF-8 bytes of your text. SHA-256 always returns 32 bytes, SHA-512 returns 64, SHA-384 returns 48 and SHA-1 returns 20, each printed as two hex digits per byte. Hashing is one-way: you can confirm a suspected input by hashing it again, but you cannot recover the original text from the digest. The same input always produces the same output, and changing one character produces a completely different one. MD5 is deliberately absent, because it is broken for collision resistance and Web Crypto does not expose it. Input is capped at 100,000 characters so the page stays responsive on a slow device.

Worked example

The SHA-256 digest of the text abc is ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad, which is 64 hex characters. The SHA-1 digest of the same three characters is a9993e364706816aba3e25717850c26c9cd0d89d, only 40 characters, so the algorithm matters when you compare two digests.
