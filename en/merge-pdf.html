Merge PDF files

Add two or more PDF files, put them in the order you want, and download the combined document. The files are read and written in your browser — nothing is uploaded.

Runs locally in your browser

How it works

Each file is parsed in the browser and its pages are copied into a new document you control the order of. Pages keep their original size, rotation and content; only the container changes. The work runs in steps with a progress bar, because assembling a large document in one go can stall a slow device.

Worked example

Three files — cover.pdf (1 page), prices.pdf (3 pages) and terms.pdf (2 pages) — combine into a 6-page document in the order you list them. Moving prices.pdf below terms.pdf changes the output to 1, 2, 3, 4 pages without reopening either file.
