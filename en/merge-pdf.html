    PDF

    Merge PDF files

    Add two or more PDF files, put them in the order you want, and download the combined document. The files are read and written in your browser — nothing is uploaded.

    Runs locally in your browser

    How it works

    Each file is parsed in the browser and its pages are copied into a new document you control the order of. Pages keep their original size, rotation and content; only the container changes. The work runs in steps with a progress bar, because assembling a large document in one go can stall a slow device.

    Worked example

    Three files — cover.pdf (1 page), prices.pdf (3 pages) and terms.pdf (2 pages) — combine into a 6-page document in the order you list them. Moving prices.pdf below terms.pdf changes the output to 1, 2, 3, 4 pages without reopening either file.

    Questions and answers

    Are my PDFs uploaded?

    No. The files are read with JavaScript inside your browser and the result is written locally. Nothing is transmitted, and there is no server to receive it.

    Can I change the order of the files?

    Yes. Each file in the list can be moved up or down, or removed, before you merge. The output follows the order shown on screen.

    Why did the merge fail?

    Password-protected PDFs cannot be opened, and a very large set of files can exceed the memory your browser allows. The tool reports which file failed instead of producing a broken document.

    Will the quality or page sizes change?

    No. Pages are copied as they are, so dimensions, images and text stay exactly as they were in the source files.

    Is there a file size limit?

    There is no fixed limit — it depends on your device's memory. If a merge fails on very large files, split the job into smaller batches.
