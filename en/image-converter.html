How it works

The image is decoded by the browser and drawn onto a canvas at its original dimensions, then the canvas is encoded in the format you chose. That is a real re-encode, not a rename: JPEG uses lossy compression and has no alpha channel, so transparency is filled with white first; PNG is lossless and keeps transparency; WebP keeps it too and is usually smaller. The quality box applies to JPEG and WebP and is ignored by PNG, which has no quality setting. Dimensions never change — if you also want to resize, do that with the image resizer first.

Worked example

A 1200 × 800 PNG converted to JPG at quality 90 comes out as 1200 × 800 px: the tool never resizes, so the result row repeats the original dimensions and the only figure that moves is the byte count. Converting the same file to PNG keeps the transparency if there is any, while the JPG version fills those pixels with white, because JPEG cannot store an alpha channel.
