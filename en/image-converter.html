    Image converter

    Choose a picture, pick the format you want and see the result, its dimensions and its exact file size before you download it.

    Runs locally in your browser

    How it works

    The image is decoded by the browser and drawn onto a canvas at its original dimensions, then the canvas is encoded in the format you chose. That is a real re-encode, not a rename: JPEG uses lossy compression and has no alpha channel, so transparency is filled with white first; PNG is lossless and keeps transparency; WebP keeps it too and is usually smaller. The quality box applies to JPEG and WebP and is ignored by PNG, which has no quality setting. Dimensions never change — if you also want to resize, do that with the image resizer first.

    Worked example

    A 1200 × 800 PNG converted to JPG at quality 90 comes out as 1200 × 800 px: the tool never resizes, so the result row repeats the original dimensions and the only figure that moves is the byte count. Converting the same file to PNG keeps the transparency if there is any, while the JPG version fills those pixels with white, because JPEG cannot store an alpha channel.

    Questions and answers

    Are my pictures uploaded?

    No. Decoding, drawing and encoding all happen in this tab on a canvas. The file never leaves your device.

    Why does the JPG look slightly different?

    Because JPEG is lossy: it discards detail it judges invisible to save space. Raise the quality for fewer artefacts and a bigger file, or use PNG when the image must stay exact.

    Why did my transparency turn white?

    JPEG has no alpha channel, so there is nowhere to store transparency. The tool fills it with white before encoding; choose PNG or WebP instead to keep it.

    Does it resize the image?

    No. The output keeps the source dimensions exactly. Resizing is a separate job, so use the image resizer and then convert if you need both.

    How big a file can I use?

    30 MB, and 40 megapixels. Larger images would take long enough to lock up the tab, so the tool refuses them with a message instead.
