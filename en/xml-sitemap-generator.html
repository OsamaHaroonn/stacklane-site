XML sitemap generator

Paste one URL per line and the tool writes a complete sitemap XML file, escaping special characters and dropping duplicates on the way.

Runs locally in your browser

How it works

Each non-empty line is checked as a URL that starts with http or https and contains a domain. Lines that fail are reported with the text that caused the problem, and duplicates are removed with a count. The surviving URLs are written as url entries inside a urlset element, each with a loc element, the change frequency you picked and the priority you picked. Five characters are escaped as XML entities: ampersands, angle brackets, double quotes and apostrophes, because an unescaped ampersand makes the file invalid. The result is capped at 5,000 URLs. You can copy it or download it as sitemap.xml. The file is assembled in the browser and nothing is uploaded.

Worked example

Pasting https://YOURDOMAIN.com/ and https://YOURDOMAIN.com/list.html?tag=a&sort=2 with monthly frequency and priority 0.7 produces a file that starts with the XML declaration and the urlset element, then two url blocks. In the second block the loc line reads https://YOURDOMAIN.com/list.html?tag=a&amp;sort=2, because the ampersand must be escaped for the XML to be valid. The file closes with the urlset end tag.
